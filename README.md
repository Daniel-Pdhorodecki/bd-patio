# 🚔 Sistema de Controle de Pátio Policial

Projeto desenvolvido para praticar **MySQL e banco de dados relacionais**, simulando um sistema de gerenciamento de **veículos apreendidos em um pátio policial**. 🚗

O sistema organiza informações sobre **pátios, policiais, veículos, infrações e apreensões**, utilizando relacionamentos entre as tabelas através de **chaves estrangeiras**. 🔗

Também foram realizadas inserções de dados e consultas utilizando `JOIN` para relacionar as informações e apresentar os dados das apreensões de forma organizada. 📊

## 🧠 Conceitos praticados

* 🗄️ Criação e organização de bancos de dados
* 🏗️ Criação de tabelas com `CREATE TABLE`
* 🔑 Chaves primárias e estrangeiras
* 🔗 Relacionamento entre tabelas
* 📝 Inserção de dados com `INSERT INTO`
* 🔍 Consultas com `SELECT`
* 🔄 Utilização de `JOIN`
* ⚙️ Restrições `NOT NULL` e `UNIQUE`
* 📦 Utilização de diferentes tipos de dados

## 🛠️ Tecnologias utilizadas

* 🐬 **MySQL**
* 💾 **SQL**

## 📚 Objetivo

O objetivo deste projeto é colocar em prática os conhecimentos básicos de **bancos de dados relacionais**, entendendo como criar tabelas, relacioná-las e realizar consultas utilizando SQL.
